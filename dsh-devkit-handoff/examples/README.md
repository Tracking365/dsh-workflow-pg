# 示例说明

这两个 JSON 是 **本项目拟实现的合同示例**，不是 DSH 官方配置，不是当前已可运行的插件命令。

`devkit.config.example.json` 刻意没有填仓库、路径、模型、端点和验证命令。Codex 应在 M0 核验实际环境，并由可信配置生成本地可运行样例。未填项必须明确显示为 unconfigured；不能填入虚构模型名或自动发现/上传用户所有代码。

`null` 是待绑定值，不是绕过检查的默认授权。空的写路径或端点列表默认不授权任何对应操作。时间字段是运行器的执行预算，不是开发工期估计。调试时可按明确需要修改可信配置，但不能由执行器自行放宽。

`task.bugfix.json` 引用 `fixture-pagination`。样例生成器应创建临时仓库、可信测试与相应 verificationProfile，并通过本地测试配置映射这个引用。它不引用机器人平台、股票项目或任何用户业务仓库。

回归测试需要覆盖 undefined、0、负数、非整数、NaN、Infinity 与正整数。JSON 本身不能表示 NaN/Infinity，测试代码应在 fixture 内直接构造这些数值。

`liveEnabled=false` 是默认值。真实模型测试由使用者在已授权环境显式开启；不启用时仍应能执行离线与真实 DSH 装配测试。
